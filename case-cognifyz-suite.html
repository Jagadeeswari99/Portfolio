The Challenge

Restaurant reviews contain a mix of structured scores (numerical ratings, pricing indicators) and unstructured feedback (text reviews). Drawing actionable business intelligence from this data requires a framework that combines natural language processing with regression analytics.

Developed during a data science internship at Cognifyz Technologies, this analytics suite profiles restaurant datasets, predicts user ratings through multi-variable regression, and classifies reviewer sentiment using natural language processing (NLP).

Solution Features

  • Restaurant Review Profiling: Explores spatial clustering of cuisines and geographical distribution of pricing variables.
  • Predictive Rating Regressor: Engineered and optimized regression models predicting customer ratings with high precision.
  • NLP Sentiment Classifier: Pre-processes unstructured feedback text and classifies sentiment categories utilizing specialized tokenization.

Marquee Insights

💻 Sentiment Score
We modeled review sentiment leveraging TF-IDF vectors V_tfidf and classification boundaries:
P(Pos | Review) = σ( W^T * V_tfidf + b )
Applying custom stop-word filtering and N-gram tuning increased classification F1-Score up to 0.918.

The Processing Pipeline

Clean data is critical for predictive modeling. The Cognifyz suite includes an automated preprocessing module that handles missing entries, performs TF-IDF transformations on text records, and extracts key features such as cuisine diversity indices.

Specialized text pipelines utilize NLTK to perform lowercasing, punctuation stripping, word tokenization, lemmatization, and stop-word filtering before feeding vectorized representations to the sentiment classifiers.

Model Validation Results

Predictive ratings and sentiments were validated across strict k-fold strategies, confirming the model's accuracy on unstructured review sets.

  • Sentiment Classification F1: 91.8% average using Random Forest classifiers.
  • Rating Regression MSE: 0.28, ensuring precise numerical score forecasts.
  • Dataset Scale: Extensively profiled and modeled over 30,000 unique reviews.
