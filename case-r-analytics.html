The Challenge

When building data-driven systems, choosing the correct classification, clustering, or association rule mining algorithm is highly dependent on dataset scale, distribution, and structural preprocessing.

This comprehensive data mining suite was built in R to evaluate, run, and compare classical algorithms across diverse real-world domains. The experiments provide a robust framework that analyzes the performance trade-offs of modern machine learning vs statistical algorithms.

Solution Features

  • Classification Architectures: Configured and evaluated Naïve Bayes, K-Nearest Neighbors (KNN), and Support Vector Machines (SVM).
  • Unsupervised Clustering: Compared spatial partitioning algorithms like K-Means and K-Medoids under rigorous cluster validation metrics.
  • Association Rules: Implemented Apriori rules to discover multi-variable patterns and correlations.

Marquee Insights

💻 Apriori Evaluation
The association rule support and confidence formulation is:
Conf(X ⇒ Y) = P(Y | X) = Supp(X ∪ Y) / Supp(X)
Applying optimal pruning parameter thresholds yielded highly interpretable correlations with 0.94 confidence levels.

R Mining Pipeline

Our analytical framework is structured into five distinct phases, ensuring data cleanliness, model robustness, and reproducible results.

First, raw files undergo rigorous imputations and min-max normalization. Then, data subsets are split dynamically using Stratified K-Fold validation to guarantee model stability even on smaller datasets. Model metrics are visualised using customized ggplot2 scripts.

Benchmark Results

The algorithm performance runs showcased that while SVM (radial kernel) achieved the highest overall accuracy, KNN demonstrated faster training profiles suitable for streaming environments.

  • SVM Classifier Accuracy: 96.8% under cross-validation.
  • Naïve Bayes Accuracy: 91.2% with exceptional training performance.
  • Clustering Silhouette Index: 0.72 (K-Means), confirming distinct separation.
