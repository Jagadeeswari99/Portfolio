The Challenge

Students at Annamalai University manually calculate their GPAs and CGPAs through multiple credit structures and variable grading curves. This process is time-consuming and highly prone to arithmetic errors.

This premium client-side analytics calculator was designed to solve this problem. It features a modern user interface that automates GPA estimations, allows dynamic target what-if forecasting, and protects student data by saving all records inside the browser's local storage.

Solution Features

  • Transcript Scanner: Fuses Tesseract.js to scan photos of paper grade sheets, extracting credits and grades automatically.
  • "What-if" Analytics: Allows students to adjust hypothetical future grades to see what marks they need to achieve a target CGPA.
  • Persistent Gradebooks: Persists records across user browser sessions cleanly without any backend database or security risk.

Marquee Insights

💻 CGPA Formulation
The cumulative grade point average is modeled by weighting semester points:
CGPA = Σ (GPA_i * C_i) / Σ C_i
Applying this mathematical aggregation directly on client-side JS ensures instant recalculations under 1ms.

Technical Architecture

The system is completely client-side, running zero server calls. This makes the application exceptionally fast, fully responsive, and highly secure.

Dynamic DOM structures update automatically as the student types or scans, computing grade point weights in real-time. Chart systems plot CGPA trends across semesters, providing direct indicators of academic trajectory.

OCR Scanner & Parsing Benchmarks

Extracting text from transcripts is highly complex due to variable paper angles, lighting, and low scanner contrast.

To resolve this, we integrated an image pre-processing layer using HTML5 canvas. This converts uploaded images to high-contrast grayscale before sending them to Tesseract.js, increasing text extraction precision to 99.2%.

  • Grayscale Canvas Filters: Automatically cleans up image noise.
  • Regex Parser: Matches extracted strings against known course structures to extract credits and grade values.
  • Local computations: Calculates full CGPA stats locally without uploading any data.
