The Challenge

Modern smart security infrastructures face significant limitations when handling multi-sensory feeds under resource-constrained edge computing environments. Security systems rely heavily on single-sensor triggers (like simple PIR motion detectors), leading to false positives and high detection latencies.

This project, presented at the Advanced Computational Intelligence & Disruptive Technologies Conference, designed a smart security framework that fuses data from multiple sensor modules (PIR, ultrasonic, camera feeds) at the edge, applying light-weight machine learning algorithms to detect anomalies locally before triggering cloud alerts.

Solution Features

  • Sensor Fusion: Combined spatial data across multi-sensory arrays to confirm anomalies, reducing false triggers by 82%.
  • Lightweight Edge Anomaly Classifier: Implemented mathematical thresholds and edge-compatible regression models to run smoothly on low-power microcontrollers.
  • Intelligent Alert Protocols: Established a hierarchical alert mechanism that routes high-priority warnings within milliseconds.

Marquee Insights

💻 Fusion Formulation
The threat score S_t is calculated via temporal weighting:
S_t = w_1 * I_pir + w_2 * D_ultrasound + w_3 * C_vision
Applying this fusion threshold reduced latency down to < 45ms while maintaining excellent accuracy.

Security Hardware Pipeline

The smart architecture focuses on processing raw sensory variables as close to the hardware layer as possible. Microcontroller units (MCUs) acquire digital and analog inputs, clean them using statistical filters (e.g., median noise filters), and feed the structured arrays to an intelligent decision engine.

When a verified anomaly is classified, the system sends highly encrypted packets over a lightweight MQTT protocol to a central local hub, which manages storage, captures real-time video snapshots, and alerts end-users instantly.

Verification Metrics

The system was verified inside simulated smart spaces over 500 test scenarios, showing high robustness against environmental noise (e.g., changes in lighting, ambient wind, or small pet movements).

  • Anomaly Detection Accuracy: 98.6% under optimal conditions.
  • Average Reaction Time: 42 milliseconds from physical disturbance to local warning triggering.
  • False Positive Reduction: 82% improvement compared to single PIR-based setups.
