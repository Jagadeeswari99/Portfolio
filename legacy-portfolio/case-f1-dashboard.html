The Challenge

Formula 1 teams record gigabytes of telemetry data per lap, covering gear distributions, velocity curves, and braking profiles. However, accessing and visualising this data quickly remains a significant barrier for enthusiasts and amateur engineers.

This F1 Telemetry Visualizer provides a high-performance web dashboard that bridges the gap. It consumes live API data streams and converts raw telemetry matrices into interactive lap-by-lap charts, allowing user-customizable track-position sector comparisons.

Solution Features

  • Live Telemetry Ingestion: Connects to FastF1 APIs to parse data vectors, speed grids, throttle inputs, and coordinates.
  • Interactive Multi-Driver Plotter: Implements a client-side Chart.js layer that charts overlapping speed channels of multiple drivers simultaneously.
  • Dynamic Sector Breakdowns: Tracks individual sectors and plots precise apex speed differences across custom corners.

Marquee Insights

💻 Apex Velocity Delta
Delta timing Δt between two drivers across distance x is modeled as:
Δt(x) = ∫ (1 / v_2(x) - 1 / v_1(x)) dx
Integrating this formula in Flask allows instant timing delta calculations plotted directly on a custom web canvas.

The Telemetry Pipeline

To deliver smooth interactions, the dashboard splits processing into edge preprocessing and client rendering.

The backend engine (Flask & FastF1) pulls the official session feeds, aligns the geographic coordinate traces using distance interpolation, and serves compressed, light-weight JSON payloads to the frontend. The browser uses Chart.js to render telemetry lines smoothly.

Interactive System Benchmarks

Performance optimization is critical when drawing multiple high-frequency curves. By limiting client redraw loops and caching API responses locally, the application maintains responsiveness.

  • Response Caching: Local SQLite caching cuts subsequent API fetching from 8.5 seconds down to 0.1s.
  • Telemetry Render speed: Under 1.2 seconds to load full telemetry plots.
  • Interactive Overlays: Users can toggle specific drivers, sectors, and parameters dynamically.
